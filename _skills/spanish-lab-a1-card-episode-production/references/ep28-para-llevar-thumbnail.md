# Ep.28 `Quiero un café para llevar` thumbnail-first reference

## Trigger
Peter rejected the originally suggested Ep.28 `el/la + noun` topic as too basic grammar (`너무 기본 문법이라 건너 띄고 다음 소재`) and approved thumbnail production for the next practical topic: `Quiero un café para llevar`.

## Topic decision
- Episode: Ep.28
- Level: A1+
- One learning point: `Quiero + noun + para llevar`
- Practical Korean gloss: `포장해 주세요` / take-away order
- Scene: Madrid station café; Jin receives a takeaway coffee before travel, with Lucía/Diego nearby.

## Thumbnail workflow used
1. Generate a direct 16:9 source image with right-side scene emphasis and left-side clean negative space.
2. Prompt constraints:
   - warm Madrid train-station café;
   - Korean beginner learner receiving takeaway coffee;
   - friendly Spanish guides nearby;
   - no readable text/logos;
   - no cropped heads;
   - left 45% clean for overlay.
3. Compose Ep.7-style overlay with Pillow:
   - cream rounded panel on left;
   - coral badge: `Español A1+ · Ep.28`;
   - large outlined Spanish title: `Para llevar`;
   - Korean white pill: `포장해 주세요`;
   - teal phrase pill: `Quiero un café\npara llevar`.
4. Save both repo and delivery thumbnail paths:
   - `thumbs/a1-ep28-quiero-cafe-para-llevar.jpg`
   - `output/thumbs/frases-a1-ep28-quiero-cafe-para-llevar.jpg`
   - source image under `assets/generated/ep28-quiero-cafe-para-llevar/source-cafe-para-llevar.png`.
5. QA visually for:
   - Spanish/Korean readability;
   - no clipping/overlap;
   - character heads intact;
   - no accidental readable text/logos;
   - Ep.7-style left panel/right scene balance.
