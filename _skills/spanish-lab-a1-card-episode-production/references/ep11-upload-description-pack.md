## Key expression block pattern
For upload readability, add a Korean-labeled “오늘의 핵심 표현” block before the full guion, even if the generated metadata only contains chapters + intro + guion. For Ep.11 the useful extracted lines were:

```text
오늘의 핵심 표현:
- ¿Qué hora es? — 몇 시예요?
- ¿A qué hora sale el tren? — 기차는 몇 시에 출발해요?
- Sale a las tres. — 3시에 출발해요.
- ¿A qué hora llega? — 몇 시에 도착해요?
- Llega a las tres y veinte. — 3시 20분에 도착해요.
- ¿Cuánto tarda? — 얼마나 걸려요?
- Tarda veinte minutos. — 20분 걸려요.
- ¿En qué andén? — 어느 승강장이에요?
- En el andén dos. — 2번 승강장이에요.
- Estamos a tiempo. — 우리는 시간에 맞춰 왔어요.
```

## Reusable lesson
When the user asks for upload copy, provide a clean copy-paste pack, not just the raw `output/meta/*.md`. Start with chapters, preserve Spanish accents and timestamps exactly, add Korean labels and a concise key-expression block, then include upload settings and exact asset paths.
