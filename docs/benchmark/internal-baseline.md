## Continuity decisions for Ep.26–35

- Ep.26 and Ep.31 remain separated: statement location vs question-response location.
- Ep.27 and Ep.28 can be explicit structural lessons because previous appearances were incidental.
- Ep.29 supports Ep.32 but remains a separate number drill.
- Ep.33 combines familiar `Me gusta` and `porque`, but teaches only `Me gusta porque...`.
- Ep.34 keeps only `yo + -é`, since Ep.12/24–25 already touched past/A2-like communication without a tense-table lesson.
